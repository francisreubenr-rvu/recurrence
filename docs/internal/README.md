# Internal submission material

Working documents kept for the record. They are not project documentation and they are not kept in sync with the code.

| File | Purpose |
|---|---|
| `start_here.md` | Deadline plan, scoring rubric, pre-submit checklist, and rule conflicts found in the official documents. Written before the build day. |
| `final_form_answers.md` | Draft answers for the final submission form. Fill every placeholder before submitting. |
| `profile_review_note.md` | What each team member fills in on their own profile review form. |

These files were written for the original flat submission folder, so some paths inside them still say `prototype/`, `start/`, or `forms/`. In this repository the application lives at the project root, and these files live in `docs/internal/`.

The public write-ups, posts, and video plan are in [`content/`](../../content/) and [`video/`](../../video/).
